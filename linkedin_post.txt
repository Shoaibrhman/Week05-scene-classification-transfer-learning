Excited to share a milestone from my Applied AI coursework: my first deep learning image classifier.

Using transfer learning with a pretrained ResNet-18, I trained a model to recognise six natural scene categories (buildings, forest, glacier, mountain, sea and street) and reached 93.5% accuracy on unseen test images.

Key takeaways:
- Only 3,078 new parameters were trained at first, with the pretrained layers kept frozen, and this already gave 90.1% validation accuracy.
- Fine-tuning the final block with a lower learning rate raised validation accuracy to 93.2%.
- Error analysis showed the model most often confused glacier with mountain, which are visually similar even to a human eye.

This project showed me how much pretrained models can achieve with limited data and compute, and why careful evaluation matters as much as the accuracy number itself.

Full notebook, code and results: https://github.com/Shoaibrhman/Week05-scene-classification-transfer-learning
